# Parallel and Distributed Computing Experiments

Implementations and experimental results for **Sequential and Parallel Computing** using **OpenMP, MPI, and CUDA**, with performance analysis and benchmarking.

This repository contains implementations developed as part of the Parallel and Distributed Computing / PGC laboratory experiments. The experiments demonstrate different approaches to parallel computation and compare their performance with sequential implementations.

---

## 📌 Objectives

- Implement computational problems using sequential programming.
- Develop shared-memory parallel programs using OpenMP.
- Develop distributed-memory programs using MPI.
- Implement GPU-based parallel programs using CUDA.
- Measure and compare execution performance.
- Analyze speedup and efficiency of parallel implementations.
- Study the practical differences between CPU and GPU-based computation.

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| C / C++ | Core implementations |
| OpenMP | Shared-memory parallel programming |
| MPI | Distributed-memory parallel programming |
| CUDA | GPU parallel programming |
| GCC / G++ | C/C++ compilation |
| NVIDIA CUDA Toolkit | CUDA compilation |
| OpenMPI / MPICH | MPI execution |
| Linux / WSL | Development and execution environment |
